# 共造 共享3D打印

连接个人创作者与制造商家，让认证范围内的订单自动报价、排产和启动生产，完成后由商家取件、质检、发货，客户验收后结算。

## 当前交付

这是第一版可交互产品原型及工程起点。网页中的农场、报价、设备、付款、物流均为明确标注的演示数据。没有真实扣款、连接打印机、生产零件或支付商家。

| 目录 | 内容 | 当前状态 |
| --- | --- | --- |
| `dist/` | 自包含 HTML 网页、上传与比价、订单和农场控制台 | 可在现代浏览器运行；实际检查见 `docs/VALIDATION.md` |
| `apps/weapp/` | 原生微信小程序示例 | 源代码，需微信开发者工具及 AppID 验证 |
| `apps/mobile/` | Capacitor Android 与 iOS 容器配置 | 尚未构建或签名安装包 |
| `apps/desktop/` | Tauri Windows、macOS、Linux 工程 | 尚未构建或签名安装包 |
| `packages/domain/` | 报价、就绪条件、生产和结算规则 | 独立于界面，包含行为测试 |
| `services/api/` | 本地演示接口 | 仅回环地址；内存数据；不可作为生产服务开放 |
| `services/gateway-simulator/` | 设备网关协议模拟 | 不会向任何真实设备发指令 |
| `docs/` | 设计、领域词汇、接口、跨端部署与生产准备 | 开发交接资料 |

## 快速运行

安装 Node.js 22 或更新版本后，在项目根目录运行：

```bash
npm start
```

打开终端显示的本地地址。网页无第三方运行依赖，不需要先安装 npm 包。直接双击 HTML 可能受浏览器文件协议限制，请使用 HTTP 服务。

```bash
npm test
npm run check
npm run api:demo
```

网页为独立本地演示，与演示 API 暂未联通；二者用于分别验证产品流程和后端规则。接入真实业务时，报价、预约、付款和结算以经过鉴权的服务端为准，不能信任浏览器传回的价格或状态。

## 核心生产约束

客户上传模型，平台生成受控生产文件。未经审核的客户 G-code 不直接下发。免逐单调参依赖已经用实机验证的设备、固件、喷嘴、材料和工艺组合；不由语言模型自由决定加工参数。

打印结束后进入待取件状态。取件、清理打印板、确认材料并恢复就绪后，设备才可自动开始下一单。启动超时进入执行未知状态，查明设备实际结果前不重复启动或改派。

## 跨平台

HTML 网页是共同入口；手机 App、桌面 App 和微信小程序具有各自的运行环境、文件选择、推送、支付与发布流程。三星手机属于 Android 适配范围。详细矩阵和构建要求见 [跨端实施说明](docs/CROSS_PLATFORM.md)。

# v0.8：从模型需求到方案确认

本版让客户从自己的 3D 模型开始提出需求，由商家维护可提供的配置，并在需要时调整制造方案。网页和服务端已连接这一流程；它仍在单个所有者的沙盒空间内运行，尚未形成不同真实客户与商家之间的交易市场。

## 客户提交什么

1. 上传模型，检查预览、原始单位和尺寸；单位选择为毫米或英寸。服务端能分析 STL 的基础几何，STEP、3MF 和图片等待工程审核。上传成功不等于已经通过可制造性检查。
2. 填写数量和材料偏好。不了解材料时选择让商家推荐，不需要自行填写温度、速度或支撑参数。
3. 按需要补充用途、颜色、尺寸公差、期望收货日期和说明；不填写特殊要求时采用普通需求。**尺寸公差与打印层高分别记录**，层高不能代替精度承诺。
4. 选择商家提供的服务配置并提交需求。收货地址从账号资料读取；缺地址时先补填，客户首页不展示详细地址。

已保存的需求绑定模型版本与内容哈希、单位、数量、材料意向和收货资料版本。更换模型或修改需求应重新提交，不能把已经确认的订单悄悄改成另一套需求。

## 商家提供什么

商家可以配置工艺、材料、可接尺寸范围、层高选项和接单模式，启用或停用配置，并关联已登记设备。关联只是登记信息，不是设备认证或开打许可。自报参数不会使未经验证的机器自动进入真实生产。

| 接单方式 | 本版行为 |
| --- | --- |
| 标准模拟预估 | 仅对兼容的 FDM PLA/PETG 演示配置和简单需求生成预估方案；价格和时间来自既有沙盒模型 |
| 商家确认 | 需要材料推荐、特殊用途/颜色/公差/日期、复杂模型或其他工艺时，由商家提交方案 |

默认三家 FDM 演示配置不是平台已经签约或联网的真实农场。新配置不会自动获得真实切片、报价认证或设备执行能力。

商家审阅模型与需求后，给出材料、制作层高选项、制造金额、运费、制作工时预测、提交订单至发货的天数范围、运输天数范围和方案说明。区间用于展示预测交期，不代表已经预约产能或获得承运商保证；海外运费和税费仍需另行核实。

商家同时填写内部预计成本与工时，服务端按该商家的计价配置检查利润底线。客户只看到最终费用，不看到采购成本与利润计算证据。默认毛利率和每单/每小时最低利润仍是可调整的演示假设，不能证明真实订单一定盈利。

## 修订、确认与订单

- 新方案产生新版本。商家提交修订后，客户需要重新查看并确认当前版本；旧版不能直接下单。
- 方案有效期为 15 分钟。模型、地址、服务配置或计价配置变化时，旧方案不能继续确认；先生成与当前条件一致的方案。
- 客户明确确认方案后，生成模拟订单。服务端保存当时模型、材料、数量、价格、时间、地址与方案版本快照；付款仍是模拟冻结，没有真实扣款。
- 已确认订单不能通过方案接口直接改价、替换材料或追加收费。发生变更需要新的客户确认流程；本版不自动补扣差价。
- 请求失败时保留原请求标识重试，避免一次确认创建多笔订单。界面以服务端返回结果为准，网络错误不当作操作成功。

标准模拟方案可以进入原有演示生产队列。人工方案确认后会保存批准计划，但生产状态仍是“待生产验证”，不会自动放行到设备执行。打印完成、取件、质检、发货、物流签收、客户验收和商家结算仍是分别记录的阶段。

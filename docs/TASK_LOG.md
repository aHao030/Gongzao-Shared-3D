# 共造任务日志

本文件记录工程任务和可复查的变更范围。只记录必要技术事实，不记录账户密码、验证码、网关令牌或实际设备密钥。代码的精确差异以 Git 提交为准，测试结果以对应版本的 `VALIDATION.md` 为准。

## 2026-11-08 · v0.3 商家入口与设备接入

基线：`2da4cc622ea95379359365c04c3341ff2e6faab4`（v0.2）。本轮沿用现有站点身份与存储，不建立另一个公开站点。

### 用户目标

- 商家拥有单独入口，客户页面减少商家操作的干扰。
- 商家可以查询已经接入平台的设备，并看到设备数量和连接状态。
- 提供设备检测与批量添加流程，覆盖已联网但尚未登记的设备。
- 取消原青绿色主色，改为黑白主色、留白和简洁层级。

### 实施记录

| 变更 | 位置 | 设计理由 |
| --- | --- | --- |
| 独立商家入口与工作台 | `dist/` 网页资源；本地与 Worker 路由 | 商家和客户各自聚焦当前操作；深链接可以直接打开对应入口 |
| 商家资料、设备登记、网关与扫描状态 | `services/platform/merchant.mjs`、`merchant-http.mjs` | 由服务端检查所有者、扫描归属和状态；持久化查询结果 |
| 单次配对与受限网关接口 | 商家 HTTP 与网关接口 | 浏览器登录和设备网关凭据分开，网关不能发起生产 |
| 本地只读发现程序 | `services/device-gateway/` | 商家电脑读取局域网设备信息，云端不扫描局域网 |
| 黑白视觉与导航精简 | `dist/styles.css`、页面和图标资源 | 降低视觉噪声，保留必要状态文字与明确主操作 |
| 操作与边界说明 | `README.md`、`MERCHANT_GUIDE.md`、`IMPLEMENTATION_V0.3.md` | 区分已实现、演示、需要本地网关和仍待实机验收的能力 |

### 关键决定

1. 独立商家入口沿用平台身份；自助建立商家资料不宣称企业审核已经完成。
2. 真实发现必须有已配对且在线的本地网关。网关只做受支持协议的只读识别，不执行打印控制。
3. 发现候选与添加登记分开；需要授权、离线、不支持或过期结果不能自动当成可用设备。同一网关的重复导入去重；同一商家下其他网关已登记的同协议/地址或标识会阻止重复登记与自动接管。
4. 样例流程只在明确选择演示后出现；没有真实设备时不使用样例伪造检测成功。
5. 新设备登记册不直接并入旧沙盒生产设备，真实制造能力继续关闭。
6. 配对令牌只用于受限网关接口，服务端保留摘要；设备 API 密钥只留本地配置。代码、文档和日志不包含真实凭据。
7. 核对到私人托管还有平台服务访问边界：新增可选本地 `siteAccessToken`，不从网页下载或自动获取平台级凭据；本地闭环和托管访问分别验收。
8. 继续保留 v0.2 的客户报价/订单/模拟履约回归；原生手机、桌面与微信工程不因网页改版而视为已完成上架。

### 验证与发布

本轮实现与检查正在由主流程汇总。最终自动化数量、构建、网页验收、部署版本及已知限制，以 [VALIDATION.md](VALIDATION.md) 的 v0.3 记录和最终交付信息为准。没有真实农场、真实打印机或生产资金操作的验证证据时，不将这些项目标记为通过。

## 2026-11-08 · v0.4 账号地址与支付方案

基线：`c7cdcd13b8c2e489915321df508bf4d98a2344fc`（v0.3）。

- 用户要求首页不展示地址，在注册/完善资料时保存；缺地址时在费用测算前弹窗填写。
- 新增 owner 作用域客户资料、地址版本、服务端区域推导、旧报价失效与订单地址快照；重置模拟订单保留资料。
- 网页删除收货地区选择器并增加账号资料入口。首次资料提示可跳过，点击测算再补填；保存自动继续，取消不生成默认地区报价。
- 同步共享 API 客户端及微信工程资料入口，保持未接微信鉴权时拒绝远程业务，未进行真机验收。
- 用户追加全球主流支付设计。核查微信平台收付通、支付宝、Stripe Connect、PayPal Multiparty、Adyen 官方能力，将付款与商家结算、银行出款拆分，并记录持款上限和争议退款规则。
- 本轮支付成果为接入设计和页面说明；演示按钮明确标注模拟付款，不把通道名称或沙盒状态当作真实支付已接通。
- 检查浏览器请求幂等缓存，禁止在缺少 Web Crypto 的环境将地址明文存入 sessionStorage；相关回归由独立审查补充。
- 源码、文档与测试更新保存到原项目。线上部署和 Windows 本地目录属于不同环境，本地需要下载并覆盖更新代码，保留原 `data`。

验证数量与范围见 `VALIDATION.md` 的 v0.4 节，不将模拟交易、协议替身或窄屏浏览器检查视为生产/真机验收。

# 共造界面设计

主要任务是上传模型、理解交付规格、比较价格与交期。客户首页让上传入口最突出；商家工作台让正在生产、待取件和异常任务最突出。

## 视觉规范

| 项目 | 规范 |
| --- | --- |
| 主色 | 青色 `#087F8C`，用于主要操作和当前导航 |
| 背景 | `#F7F8FA`，内容面板白色 |
| 正文 | 深蓝灰 `#172B3A`，次要文字 `#667585` |
| 边框 | `#E5EAF0`，轻量阴影 |
| 间距 | 4px 基础，常用 8、16、24、32px |
| 圆角 | 内容卡片 12 至 16px，按钮 8 至 10px |
| 字体 | 系统中文无衬线字体，正文至少 14px |
| 状态 | 文字与图形共同表达，不只依赖颜色 |
| 动效 | 仅用于反馈，尊重减少动态效果设置 |

桌面采用侧栏和两到三栏内容；手机采用单栏、易触达操作与可折叠次要信息。禁止横向溢出遮挡主操作。模型预览与参数编辑应同时可理解，重要公差、材料和交付要求不能被装饰挤掉。

## 页面与主操作

| 页面 | 主操作 | 必须明确显示 |
| --- | --- | --- |
| 工作台 | 开始定制 | 最近订单和下一步 |
| 上传与配置 | 获取报价 | 单位、尺寸、材料、数量与审核条件 |
| 比价 | 选择制造方案 | 总价、发货区间、到货区间、质量等级 |
| 订单 | 查看当前阶段 | 生产、物流、验收与资金分别展示 |
| 农场工作台 | 处理待取件与异常 | 可接单、运行中、待清台、故障 |
| 设备接入 | 登记接入能力 | 监测、上传、启动的分别授权 |

正式版本所有演示数字将替换为可追溯的数据；零记录时使用清晰空状态，不制造在线商家或成交量。网页与小程序共享设计 token 和文案，不声称同一 DOM 组件能直接运行于小程序。

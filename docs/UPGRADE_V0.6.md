# 共造 v0.6 · 更新与使用

线上地址保持不变： https://shared-fabrication-studio.sweetowlet132.chatgpt.site/

网页发布后刷新即可使用新版；电脑上解压的 v0.3/v0.4/v0.5 不会自动替换。

## Windows 保留数据升级

1. 在正在运行服务的命令窗口按 Ctrl+C 停止服务。
2. 备份原项目的 `data` 文件夹（包括数据库及同目录文件）；不要分享给其他人。
3. 解压 `Gongzao-Shared-3D-v0.6.zip`，把包含 `package.json`、`dist`、`services` 的内层目录内容复制到原项目文件夹，替换同名代码文件。保留原来的 `data`，不要删除或换成空目录。
4. 在原项目目录的资源管理器地址栏输入 `cmd`，执行 `npm start`。本地运行不需要先安装开发依赖。
5. 打开 http://127.0.0.1:3000 ，按 Ctrl+F5 刷新。使用之前的浏览器会话，启动行应显示 v0.6。

如果仍使用原下载路径，可执行：

```bat
cd /d "C:\Users\11200\Documents\Gongzao-Shared-3D-v0.3\Gongzao-Shared-3D-v0.3"
npm start
```

文件夹名称不影响版本，可以保留旧名称。需要 Node.js 24；保持命令窗口开启。服务停止期间请不要提交订单。线上账号与本机沙盒不自动同步。

## 新增流程在哪里

- 商家工作台 → 计价：设置每个演示农场的成本、目标毛利率、最低订单利润及每设备小时利润。全部默认值是可调演示假设。
- 费用明细：查看包围盒估算的预计每板件数、板数和单件制造价；这不代表排版或切片已经完成。
- 新版模拟结算：商家应收与平台服务费分开；退款仍按客户原付款总额。旧已结算记录保留，不重做分账。

- 客户首页 → 费用明细：查看报价有效期、估算依据和预计日期。
- 客户订单 → 确认收货验收：状态变为“验收完成 · 待结算”。退款/争议入口和订单记录在同一张卡片。
- 商家工作台 → 订单演示 → 结算与售后：申请模拟结算、模拟结果或处理退款。申请成功不等于处理成功，成功也不代表银行到账。
- 商家工作台 → 设备：查询已登记设备，查看“识别详情”。过期观察不继续当在线，观察可用也不代表实机可打印。

## 当前运行边界

本版还是服务端持久化沙盒：付款、生产、运单及结算不执行真实业务。自动识别仅有 Moonraker/OctoPrint 只读协议路线，尚未实机验收。真实支付产品、物流订阅、受控切片、商家权限隔离和原生签名上架仍需后续开发。

历史已结算订单不会重结算；旧订单缺少的新分析字段不补造。新未生产订单取消后，会显示待处理退款，需在商家演示页面处理。

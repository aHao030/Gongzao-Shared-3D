# v0.9.6 拓竹打印机接入指南

共造网关在打印机所在的局域网发现设备。商家可从网页一次登记多台机器。输入每台打印机授权的局域网访问码后，可读取设备实际返回的状态和进度。设备列表会分别显示广播发现、只读认证、最近观察和过期状态。

## Windows 商家首次使用

1. 在安装 Node.js 24 的农场电脑上，将电脑和打印机连接到同一局域网。打开共造并登录商家账号，进入「商家工作台 → 设备 → 连接网关」，点击「下载 Windows 网关」，再单独下载该店的配对配置。若使用本地版，在农场电脑打开 `http://127.0.0.1:3000/merchant/login`。
2. 在**完整解压**的轻量网关目录（或完整项目目录）双击 `BAMBU-GATEWAY-WINDOWS.cmd`。首次使用按向导输入下载的配置文件路径，核对平台地址。家庭或商家本地版可以直接使用本地配置；私有托管站点另需部署负责人提供站点服务授权，可在向导菜单中填写。网关令牌和打印机访问码分别授权不同连接。
3. 在向导选「1 启动网关」，保持农场电脑和该窗口运行。在网页「设备」点「一键接入拓竹」；有多个在线网关时选择对应农场。网关监听本次广播，返回后自动登记发现的拓竹设备。此前登记的设备沿用原记录。单次最多登记 100 个候选。只用广播时无需逐台输入访问码；需读取状态的机器要由商家逐台本地授权，每个网关最多配置 100 台拓竹授权设备，后台分批刷新，每批最多 32 台。
4. 若设备显示「待授权」，打开第二个同名向导窗口，选「2 添加/更新设备授权」。从本机发现列表选择打印机，或手动填写局域网 IPv4 和机身序列号。核对屏幕或机身标识，输入该台打印机的 LAN 访问码。可选「6 试读设备状态」在农场电脑上独立验证该台设备。向导保存后原网关窗口会在下一轮轮询重新加载授权。网关默认验证厂商证书和设备序列号。只有掌握独立核实的单机证书 SHA-256 指纹时才填写指纹选项。
5. 保持网关运行。再点一次「一键接入拓竹」可以立即重新核对；后台会定期对已登记设备发起监测。网页「查询已接入设备」显示平台最近收到的结果。按机身屏幕核对实际型号、空闲/打印中/暂停和进度；第一次观察尚无具体状态时会显示待确认。网关心跳或设备观察过期后，页面停止将旧值当作当前状态。

本机授权配置保存在当前用户的 `%LOCALAPPDATA%\Gongzao\gateway.private.json`（macOS/Linux 可运行 `node tools/bambu-gateway.mjs`）。每台打印机的访问码只留在农场本机。换码后在向导更新原台设备；移除授权使用向导选项 4。停用整台网关可在商家工作台撤销该网关。配对下载文件同样需妥善保管。

## 各阶段能看到什么

| 商家看到的情况 | 意义及操作 |
| --- | --- |
| 登记成功、待授权 | 网关看到局域网广播；先比对机身，添加本机只读授权后再判断运行状态。 |
| 已连接并有实时报告 | 网关经 TLS 验证打印机身份、通过访问码认证并收到打印机报告。可显示报告中的打印状态和百分比；缺少字段时显示未知。 |
| 扫描结果为空 | 确认打印机已开机、网关实际运行在农场同网段的电脑，并且当前固件支持局域网发现。访客 Wi-Fi、VLAN 隔离或 Windows 网络策略可能使广播送不到网关。可在向导里手动添加已知设备的本地地址及授权。 |
| 仅发现部分设备 | 报告可能因本轮目标数上限、广播监听不可用、地址冲突等不完整。上次已登记、此次漏见的设备保留上次观察时间，之后自然过期。对照现场清单按网络分区设置网关，再做定向复查。 |
| 授权或证书核对失败 | 核对设备屏幕、序列号、厂商当前固件支持情况和本地访问码，必要时更新本机授权。若固件限制第三方读取，保留待授权状态，可使用厂商支持的监控方式。 |
| 可读取状态，但没有开印按钮 | 本版的拓竹接入权限覆盖登记、读取和刷新。订单付款、切片文件发送、物理启动、停止及 AMS 选料仍需单独实现并进行现场验收。 |

网关被动监听本地 IPv4 上的 UDP 1990、2021（广播或组播）。读取状态时，由网关向已核准打印机的 TCP 8883 发起 TLS 连接，使用固定设备报告主题；部分机型采用增量报告，网关可请求只读状态快照。跨网段、隔离或受管理的网络，应由农场网络负责人确认局域网流量能否到达。无需向公网开放打印机端口。

## 型号名称与真机验证

下表是 v0.9.6 对广播型号代码的名称映射。实际连接是否可用，还取决于机型、固件、局域网可达性和当前授权。型号代码不能证明能读状态或机器已能承接订单。

| 系列 | 可识别名称 | 型号代码 |
| --- | --- | --- |
| X1 | X1 Carbon、X1、X1E | BL-P001、BL-P002、C13，兼容旧款 X1 广播名称 |
| P | P1P、P1S、P2S | C11、C12、N7 |
| A | A1 mini、A1 | N1、N2S |
| H2 | H2D、H2S、H2D Pro、H2C | O1D、O1S、O1E、O1C / O1C2 |

未认识的型号保留「型号待核对」。同一序列号的重复广播不会增加台数。不同身份占用同一地址或同一序列同时出现在两个地址时，应由农场人员排查，平台不会据此自动调度。端到端回归使用独立测试账号、真实本机 HTTP/SQLite、合成广播和状态观测；TLS/MQTT 读状态另有本地 TLS 服务测试。此版本尚无使用商家真机取得的型号/固件认证。

## 农场现场验收

用机身和固件版本逐台登记结果。第一次试点可以先验证两台同型号加一台不同型号，记下打印机序列末四位、网页设备 ID 和实际观察时间。

| 现场动作 | 通过条件 |
| --- | --- |
| 登记三台，重复检测 | 总数保持三台，店铺之间相互隔离；身份不明的广播不被视为已经认证。 |
| 对其中一台填写授权，另一台保持待授权 | 授权只影响选中的机器。读取状态与机身一致；无授权的打印机无打印进度。 |
| 对正在生产的机器观察进度和断线 | 实际状态和进度随新报告更新；断线或旧观察过期后不显示仍在运行的旧百分比。 |
| 测试设备获取新地址、断线再连接 | 同网段的新地址需重新验证原设备身份和 TLS 证书，成功后沿用原登记 ID。跨网段、重复序列号或地址冲突时，在本机向导核对并更新授权。 |
| 撤销设备或网关授权 | 后续读取停止，历史登记仍可查看；报告中不出现 LAN 访问码与明文序列号。 |

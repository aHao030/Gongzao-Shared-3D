# 共享制造领域词汇

**客户**：提交定制需求并购买制造交付的个人或机构。避免用“用户”混指客户、商家和运营人员。

**农场**：由一家商家管理的生产场地及其设备、人员和可售产能。CNC 商家也可归入制造商家，面向用户时不强制称为打印农场。

**模型版本**：一次确定的产品几何与单位定义。客户修改后形成新版本，旧报价不自动沿用。

**工艺模板**：针对确定设备配置、材料和质量目标验证过的一套加工规则。不是单一温度或速度值。

**生产计划**：针对模型版本和交付要求确定的制造安排，包含工艺、设备适配、耗材及预计时间。

**报价**：商家对确定交付规格、价格和交期的限时承诺。估价不等于可直接支付的有效报价。

**产能预约**：为订单保留的机器时段和材料额度。预约失效不表示已经启动的设备会停止。

**生产尝试**：一次实际制造过程。返工是新的尝试，不能覆盖原失败过程。

**已备机**：现场完成必要准备并允许在指定时段自动接单的设备状态。空闲和在线不足以证明已备机。

**待取件**：加工已结束、零件仍占用设备或工作区的状态。未清台前不能接受下一次自动启动。

**验收**：客户按订单约定确认交付结果的过程。物流签收不是质量验收。

**结算**：满足验收与争议条件后通过支付机构分配订单款项的过程。接口受理不是结算成功。

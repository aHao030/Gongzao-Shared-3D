# 共造 v0.6 · 批量报价与商家收益保护

本次调整针对 FDM 沙盒：同一订单的多件模型可以在一块打印板上生产时，应按整板估算并分摊准备成本，而不是把单件报价直接乘数量。所有默认成本和利润目标都是可调整的演示假设，不代表行业平均价、实际商家成本或保证利润。

## 计价原则

1. **整板与单件分别核算。** 材料和逐件后处理随数量增长；准备、装料、清台等按板计入。整板机时仍随总挤出量增长，不能把几十件的整板视为只打印一件。
2. **不固定打折。** 批量优惠来自固定成本分摊。平台不以数量达到阈值为由，直接在商家应收款上打折。
3. **商家设置自己的底线。** 制造应收按三者中的最高值定价：目标毛利反推价、成本加最低订单利润、成本加最低每机时利润。金额向上取整到分。
4. **平台费另列。** 当前方案在制造应收之外向客户加平台服务费；运费补偿另外列出。不得先按商家净收入算利润，再从这笔收入中重复扣平台费。
5. **报价是快照。** 已下单订单沿用下单时的报价和分账，不随之后的计价设置变化。未使用报价在对应计价版本变化后必须重新测算。
6. **不以界面隐藏代替数据隔离。** 客户报价与订单响应只含客户报价、分账和批量规划等公开字段；商家成本、利润与配置仅从需开通商家资料的接口读取。当前仍是一个 owner 内模拟双方，尚未实现商业买卖双方角色授权。

设：

- `C` = 预计生产成本（含所配置的材料、机器、电费、人工、后处理、损耗等）。
- `r` = 目标订单毛利率，分母是商家的制造收入。
- `H` = 预计整批设备占用小时。
- `P_order` = 最低订单利润。
- `P_hour` = 最低每机时利润。

制造应收为：

```text
R = max(C / (1-r), C + P_order, C + H × P_hour)
```

订单预测毛利为 `R-C`，预测毛利率为 `(R-C)/R`。这不是企业净利润；未计入或配置不准确的税费、支付渠道费用、场地管理成本、返工和停机都会改变实际结果。30% 目标毛利不等于成本加价 30%；成本加价 30% 对应的收入毛利率约为 23.1%。

## 排板与时间边界

当前排板只用模型包围盒和演示打印板尺寸进行规则网格估算，允许平面 90 度旋转并预留间隔。它没有执行切片器、支持结构生成或真实排样，不验证裙边、支撑、擦料塔、工具头碰撞、首层稳定和物理可制造性。页面必须保留“预计”与“未切片”提示。

本轮只对单一订单内部计价，不跨客户拼板，不等待其他订单凑满，不承诺填写的数量一定装得下。到货区间继续属于演示估算，不能当作已预留产能或承运商交期。

## 分账与历史订单

客户支付总额、平台服务费、商家制造应收、运费补偿分别记录。商家应收包含制造应收与约定的运费补偿；模拟结算只使用商家应收，整单模拟退款仍退客户支付总额。

旧 v0.5 已完成结算的记录保留历史事实，不通过升级改写已完成金额。尚未结算的旧订单仅能按已有报价中的平台费和运费推导分账，并标明是历史推导；不得补造当时不存在的成本、毛利或排板证据。

旧版已有待处理结算申请如果记录的是客户总额，不能直接模拟成功；接口返回 `LEGACY_SETTLEMENT_REVIEW_REQUIRED`。需将旧申请明确标记为失败，再申请按商家应收结算，原申请金额留在历史中。没有足够旧报价字段的记录也不能自动结算。

## 一板 30 件的解释算例

以下是为了说明计算方法的**假设算例，不是市场均价、平台默认报价或行业利润统计**。假设一板 30 件，每件成品 10 g；含支撑与损耗的整板用料 330 g，设备占用 8 小时。

| 成本项目 | 假设与计算 | 整板成本 |
| --- | --- | ---: |
| 耗材 | 0.33 kg × 40 元/kg | 13.20 元 |
| 折旧与维护 | 8 小时 × 0.80 元/小时 | 6.40 元 |
| 电费 | 0.12 kW × 8 小时 × 1 元/kWh | 0.96 元 |
| 准备与清台 | 10 分钟 × 30 元/小时 | 5.00 元 |
| 逐件后处理 | 0.5 分钟 × 30 件 × 30 元/小时 | 7.50 元 |
| 包装 | 整单假设 | 2.00 元 |
| 经营分摊 | 整单假设 | 5.00 元 |
| 风险预留 | 整单假设 | 3.00 元 |
| **合计** | **未含运费、平台费、税费及支付渠道费** | **43.06 元** |

同样的成本，在不同制造收入下：

| 商家整板制造收入 | 平均每件制造价 | 预计制造利润 | 收入毛利率 | 每设备小时预计利润 |
| ---: | ---: | ---: | ---: | ---: |
| 60.00 元 | 2.00 元 | 16.94 元 | 28.2% | 2.12 元 |
| 75.00 元 | 2.50 元 | 31.94 元 | 42.6% | 3.99 元 |
| 90.00 元 | 3.00 元 | 46.94 元 | 52.2% | 5.87 元 |

这说明只看毛利率不够。8 小时的订单即使毛利率 42.6%，也仅产生约 3.99 元/设备小时的预计利润。若商家要求至少 5 元/设备小时，该假设成本下制造应收至少为 `43.06 + 8 × 5 = 83.06` 元，另与目标毛利价、最低订单利润价比较取高。实际切片时间、失败概率、后处理和经营成本变化时，需重新核算。

程序默认成本与本算例不同。本算例将经营分摊和风险以固定金额单列；当前程序没有独立“经营分摊”字段，风险按已配置成本的百分比预留，不能把本算例当作当前程序的精确输出。商家仍需核对未录入的经营开销。

## 运行与使用

本地运行 `npm start`，在网页商家入口开通演示商家资料，进入“计价”导航或概览的“批量计价”。选择当前账号内的演示工场，设置成本、目标毛利率、最低订单利润和每设备小时最低利润，确认演示参数后保存。返回个人创作入口重新询价，即使用新设置；已有订单仍使用原快照。

默认目标毛利率为 30%、最低订单利润为 5 元、最低每设备小时利润为 5 元，均为可调整的演示参数，不是平台承诺或行业正常利润。PLA/PETG 默认采购价分别为 60/75 元每 kg；默认产出速度为 20 g/小时、每板预热 5 分钟。这些值需用商家的真实设备、材料和切片结果校准。

微信小程序远端映射增加预计板数、单板容量、平均制造单价及订单费用拆分；工程审核显示“待工程报价”。本机模式仍为旧版本地示例算法，页面明确标识。服务端微信鉴权默认仍关闭，未提供已能真机登录的承诺。

真实支付、实机开打、跨商家权限、精确切片及企业财务核算仍未接入。

## 接口与数据边界

金额均使用人民币分，毛利率与风险比例使用基点（`3000` = 30%）。

| 接口或字段 | 用途与约束 |
| --- | --- |
| `GET /api/v2/merchant/pricing` | 当前 owner 已开通商家资料后读取 `profiles`、最近 60 份 `quoteEconomics` 和 `orderEconomics`。无会话 401、未开通 403。 |
| `POST /api/v2/merchant/pricing` | 携带 `Idempotency-Key`，提交 `{farmId, expectedRevision, profile, demoAcknowledged:true}`。`profile` 必须含全部可编辑参数，不含 farmId/名称/版本/更新时间等只读字段。 |
| `profile.materialCostCentsPerKg` | 必须包含 PLA、PETG 两项采购价。 |
| `profile` 其他可编辑参数 | `machineCostCentsPerHour`、`estimatedThroughputGramsPerHour`、`warmupMinutesPerPlate`、`electricityCentsPerKwh`、`averagePowerWatts`、`laborCentsPerHour`、`orderSetupMinutes`、`plateSetupMinutes`、`finishingMinutesPerPart`、`packagingCentsPerOrder`、`riskReserveBps`、`targetMarginBps`、`minimumOrderProfitCents`、`minimumProfitCentsPerMachineHour`。 |
| `expectedRevision` | 必填且需匹配当前配置版本；过时写入返回 `PRICING_REVISION_CONFLICT`。不变配置不提升计价版本。 |
| `quote.pricingRevision` | 对应报价所用计价版本；版本变更后旧报价下单返回 `PRICING_CHANGED`。 |
| `quote.batch` | 客户可见的包围盒网格估算；包含板数、每板容量、各板件数。`verified`、`mixedOrders`、`waitForOtherOrders` 均为 false。 |
| `quote.pricingSummary` | 客户可见的制造费、平台费、运费、商家应收、客户总额和平均制造单价。 |
| `order.settlementBreakdown` | 下单分账快照，`source` 为 `V0_6_QUOTE`；旧未结算订单可核验推导时为 `LEGACY_DERIVED`。 |
| 内部收益证据 | 成本分类、成本总额、预测利润、预测毛利率、利润下限及 `profileSnapshot` 仅放在持久化内部 `pricingEvidence`，经商家接口读取；不进入客户 workspace、报价或订单响应。 |

当前演示平台服务费为制造费的 7%，按分向上取整后向客户另收。分账必须满足：`制造费 + 运费 = 商家应收`，`商家应收 + 平台费 = 客户总额`。这属于沙盒费率，不代表最终商业费率。

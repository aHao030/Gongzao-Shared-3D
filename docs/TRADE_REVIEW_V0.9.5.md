验收日期为 2026 年 11 月 11 日。使用 Node 24、本地 HTTP 服务与 SQLite 创建独立测试账号，所有模型、地址与金额均为合成测试数据。D1 部分使用本地 SQLite 执行项目的部署迁移和生产查询，并模拟 D1 的绑定、结果集与变更计数。

## 买家和商家会遇到什么问题

| 质询 | 验证动作 | 结果 |
| --- | --- | --- |
| 同一模型问两家店，一家能否看到给另一家的图纸或消息？ | 用三个注册账号创建两个会话。客户绑定原访客工作空间，向甲店授权原件，仅向乙店分享概要。两家各用同一个请求号并发重发自己的回复。 | 甲店收到原始 STL 字节，乙店的概要会话无法下载。访问对方的会话返回 404。回复各保存一次，收件箱各只有本店会话。两份会话均未出现买家地址和商家私有成本字段。 |
| 商家修改利润要求后，客户昨天看到的预算会变吗？ | 在未填地址时先算三件的平台参考价。给甲店设置最低整单利润要求，分别预览甲乙两家并发起咨询。甲店提价后再次预览、开新会话，最后关闭甲店入口。 | 两家各自的选店预览和会话冻结结果逐字段一致。甲店采用店铺费率，乙店沿用平台参考。提价后甲店的新预算上升，历史预算保持原值。入口关闭后新预览返回 404，旧记录仍可读。 |
| 客户撤回图纸，网络重试或旧页面会不会重新授权？ | 撤回、重试同一请求，再从旧版本尝试授权。检查商家权限、恢复授权及另一个店铺的下载状态。还测试了下载期间发生撤回。 | 撤回阻止后续下载并只记录一次。商家无法代替客户恢复，旧版本返回 409。客户在当前版本明确确认后可恢复。下载返回前再次核对权限。已交付给对方的副本无法远程收回。 |
| 会话写满时，客户还能否保护自己的原件？ | 客户共享 STL，商家连续留言至 300 条。再发普通消息，撤回授权并重试，重新尝试下载和开启共享。 | 普通消息触及上限后，撤回仍成功。原件下载返回 403，已满会话无法再启用共享。 |
| 买家点确认时，商家正好改价，该按哪一版？ | 客户确认第一版的同时，让商家修改金额。另测旧版本、过期与重复确认。 | 两个竞争操作只有一个先提交成功。改价先提交时需核对新版后再次确认。确认先提交时原价锁定。双方工作空间、订单和设备状态均未改变。 |
| 一条已读回执被网络延迟，新消息还会提醒吗？ | 在 D1 契约测试中挂起已读查询，先由另一请求写入新消息，再让旧回执提交。另建 27 个相同毫秒的询盘，使用两页读取。 | 验证旧回执的条件写发生冲突并重试。新消息保留一条未读，迟到的更早回执也不会清除它。两页合并恰好返回 27 个不同会话。 |
| 自动估价与切片、正式报价使用相同口径吗？ | 比较相同材料和配置的测算与沙盒报价，替换切片数量和模型版本，另试 CNC、树脂、无效几何。 | 有匹配依据时按整单切片计价。失去匹配时回到几何估算。工程复核项目显示待评估，金额字段为空。正式比较时单列运费。 |

## 审查后修正的流程

- 首页把真实联系入口标成“选店并联系商家”，另列“演示询价配置”和“提交演示询价”。点击选店后，列表来自已开启咨询的商家账号。快速估价区的三家示例农场分别标有“示例档案”。
- 咨询弹窗在选店时会重新请求该店预算。旧界面在此处仍显示平台参考值，可能低于商家设置的利润要求。服务端现使用开启会话时相同的店铺和模型计算规则，并分别在三件平台预算、甲店、乙店以及甲店改价后进行了核对。如果商家在预览和发送之间调整了配置，会话保存发送时的测算；客户可以看到这份预算再讨论报价。
- 客户可以在历史会话中撤回原件下载授权。满额会话专门允许撤回，读取文件结束时还会复核共享版本。商家发送的整数分报价按版本确认，页面区分了报价确认和后续交易。

卖家收件箱遇到两个同名模型时，原列表会重复显示文件名和自己的店名。列表及会话标题现在都显示该笔咨询的短号，展开概要可见完整询价号。回归使用两个相近的会话标识核对显示，同时保留客户账号与地址的隐私。

## 一组可复算的示例

内置示例支架选择毫米、标准精度、自动比较材料，未设置店铺专属费率，也未提供切片结果。金额为人民币，沿用该版本的沙盒配置，包含制造、基础包装和平台服务费。运费、税费和特殊后处理另计。

| 数量 | 预估整单 | 每件约 |
| ---: | ---: | ---: |
| 1 件 | ¥21.96–23.68 | ¥21.96–23.68 |
| 3 件 | ¥48.04–53.14 | ¥16.01–17.71 |
| 20 件 | ¥273.54–307.14 | ¥13.68–15.36 |

每件金额按整单金额除以件数后四舍五入至分。商家报价还会说明整单价格、是否含运费、预计发货天数、工艺条件和有效期。聊天中的确认只记录双方接受的报价版本，没有收款或派发打印指令。

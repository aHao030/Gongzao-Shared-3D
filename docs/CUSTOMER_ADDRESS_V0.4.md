# v0.4 收货地址与本地升级

## 客户怎么用

1. 进入客户首页。首次使用会出现“完善账号资料”，填写称呼、收货人、电话、国家/地区、省市区与详细地址；也可选择“稍后填写”。
2. 配置模型、材料和数量，选择“测算费用”。没有保存地址时，系统弹出“填写收货地址”；保存后自动继续，不需要重新配置作品。
3. 已填写的地址从账号资料读取。首页不展示地址内容；修改地址请点击顶部“账号资料”。
4. 地址修改后重新测算费用。已经创建的订单保留当时地址，更新账号资料不会偷偷改变历史订单。

其他国家/地区可输入两字母代码及省州、城市。当前沙盒只对目录内地区估价；其余地区进入询价确认。收货地址未经过地址核验或真实承运商校验，不保证实际配送可达性或运价。

托管网页使用当前平台身份；本地使用当前浏览器沙盒会话。两者资料不自动同步；清除本地 Cookie 后不能自动找回原身份。此版本没有替代第三方登录页面的账户注册流程。

## 更新已启动的 Windows v0.3

你的旧项目目录是：

```text
C:\Users\11200\Documents\Gongzao-Shared-3D-v0.3\Gongzao-Shared-3D-v0.3
```

1. 在原命令窗口按 `Ctrl+C`，确认服务停止。
2. 解压 v0.4 压缩包，将内层（含 `package.json`、`dist`、`services`）所有文件复制到上面的旧目录，选择替换同名代码文件。**保留原来的 `data` 文件夹**；发布包不包含数据库和密钥。
3. 在原目录运行 `npm start`，浏览器打开 `http://127.0.0.1:3000`，按 `Ctrl+F5` 刷新。窗口应显示“共造 v0.4 沙盒”。

正常本地运行使用 Node.js 24 内置模块，不必重复安装开发依赖。不要将新包的外层文件夹套进旧项目根目录，也不要直接打开 `dist/index.html`。线上网站已经发布新版本，不代表你电脑里的文件会自动更新。

## 支付入口

网页页脚“支付与结算”说明计划支持的支付方式和验收后结算规则。当前确认订单只执行“模拟付款并下单”，不会扣款。真实通道需要完成商户准入、服务端支付回调与账本、退款和结算联调之后启用；详见 `PAYMENTS_DESIGN_V0.4.md`。

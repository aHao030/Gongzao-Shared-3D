# 微信小程序 · 原生演示工程

此目录是原生 WXML / WXSS / JavaScript 项目，不需要 Taro、npm 安装或外部构建工具。提供“定制 → 示例报价 → 演示订单”三个页面。

## 运行

1. 安装微信开发者工具，选择导入项目。
2. 项目目录选择本目录 `apps/weapp`；`miniprogramRoot` 为 `./`。
3. 当前 `project.config.json` 使用 `touristappid`，用于游客模式本地预览。实际预览、体验版、登录或发布请替换成自己主体注册的真实 AppID，并按开发者工具当前权限操作。
4. 在工具内编译，依次点击“使用内置示例模型”“查看示例报价”“选择并保存演示订单”。订单页可手动推进至模拟结算；金属 / CNC 路线先显示工程审核，所有路线均区分生产完成、取件/后处理、质检与发货。

## 演示边界

- 仅有内置零件名称和尺寸，不含真实模型文件，不解析任意上传文件，不上传任何图纸。
- 工坊、价格、工期、生产、物流、收货、结算全部是示例。没有真实付款、设备下发或承运商请求。
- 订单保存在小程序本机演示存储中，最多保留 20 条；不收集姓名、地址或其他个人资料。
- 页面中的推进按钮用于演示。正式版必须由服务端验证商家权限、生产证据、物流回调、收货和结算条件。
- 首版采用原生小程序；未来可在评估后迁移 Taro，但当前没有使用 Taro。

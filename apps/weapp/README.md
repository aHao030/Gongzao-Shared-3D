# 微信小程序 · 原生演示工程

使用原生 WXML / WXSS / JavaScript，提供定制、报价、订单和账号资料页面。默认本机演示无需外部账户或服务；不需要 Taro/npm 构建。

## 打开与体验

1. 微信开发者工具导入本目录 `apps/weapp`，`miniprogramRoot` 为 `./`。
2. 当前 AppID 是 `touristappid`，只用于允许游客模式的本地预览。体验版、登录、真机或发布按当前权限要求换成自己的真实 AppID。
3. 选择内置模型、材料和数量；查看示例报价并创建本机订单。
4. 订单可模拟推进；金属/CNC 先经过工程审核。生产完成、取件/后处理、质检、物流、收货和结算分开显示。

## 两种数据模式

- **本机演示（默认）**：本地示例工坊、报价和订单，最多保存 20 条演示订单；没有真实付款、设备命令、物流请求或个人资料采集。
- **服务端沙盒（当前受阻）**：页面提供明确入口，但 `config/service.js` 中 `AUTH_ADAPTER_READY: false` 会阻止切换。当前托管后端仅有 Sites 身份，小程序身份交换没有接通；不能复用浏览器里的 ChatGPT Cookie。

后续启用必须先由开发者完成后端接受的小程序登录/令牌交换，实现 `utils/auth.js` 的 `getAccessToken()`，配置真实 HTTPS `API_BASE` 以及微信合法域名，最后才设置 `AUTH_ADAPTER_READY: true`。切换会调用 `/api/v2/session`，仅在认证和沙盒模式均通过后成功。不要仅把标志改成 true，更不要填假令牌。

页面已统一通过 `utils/service.js` 读取数据。远端路径使用共享 API v2 客户端，网络/身份错误会直接展示，不悄悄回退成本地报价或伪成功。远端订单页只读，不允许本机推进商家生产与结算。客户验收/争议/取消仅有 API 工厂封装，尚未接入远端页面按钮。

当前模型只使用内置示例名称和尺寸；没有微信文件选择、上传或任意模型解析。API 工厂提供的二进制上传方法不等于页面已实现上传。

## 开发与验证

共享客户端源文件位于 `apps/shared/api-client.js`；副本通过 `node apps/tools/sync-client.mjs` 更新。静态与契约验证：

```sh
node apps/tools/check-platforms.mjs --target weapp
node --test apps/tests/*.test.mjs
```

这些检查不启动微信开发者工具，不执行真实认证。尚未进行微信渲染、真机运行或审核；所有服务端请求测试使用注入的本地假 transport，不向外发送假 token。

报价及创建订单的未确认请求幂等键会保存在本机并在重试时复用。AppSecret、支付密钥、真实商家密钥不得进入小程序源码；微信登录换码和密钥操作应在自己的可信服务端完成。

参考：[微信官方网络配置说明](https://pay.wechatpay.cn/doc/v3/partner/4012088031)。

## v0.4 地址补填

“账号资料”页在本机演示模式不展示输入表单，不采集真实个人地址。接通服务端鉴权后，可读取或保存收货地址；缺少地址时，报价页显示“填写收货地址”入口，保存成功返回报价页继续测算。地区由服务端推导，不再固定传华东。地址修订版本参与报价重试键，避免修改地址后取回旧报价。失败的资料保存仅在当前进程内保留重试键和待提交内容，个人资料不落本机持久存储。

该页面和客户端契约已实现，但默认 AUTH_ADAPTER_READY 仍为 false；本轮没有微信开发者工具或真机验证，也没有完成微信登录、真实支付、物流接入。
